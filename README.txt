SPORTS ACADEMY — iPHONE PROTOTYPE 0.5

This build is a mobile-first web app.

IMPORTANT:
Opening index.html directly from the iPhone Files app is not the intended final play method. The folder should be hosted on an HTTPS web server so Safari can run it as a web app and Add to Home Screen can provide the app-like experience.

Once hosted:
1. Open the Sports Academy URL on the iPhone.
2. Use the browser Share menu.
3. Choose Add to Home Screen.
4. Launch Sports Academy from the new icon.

The prototype stores its current season locally in the browser, so closing and reopening it preserves progress on that browser unless site data is cleared.

Included:
- touch-first Director Dashboard
- eight-week weekly loop
- roster
- Coach Navarro
- recruiting
- Director Attention
- simulated games
- Director Decisions
- Academy Times
- History Ledger
- end-of-season history review
- persistent local save
- web app manifest
- offline cache/service worker foundation
